# Demoblaze Automation Project

## Project Overview
This repository contains the source code developed for the Demoblaze project.

## Features
- User Registration (Signup)
- Invalid Login Validation
- Alert and Popup Handling
- Add Product to Cart
- Browser Setup and Website Navigation

## Project Structure
- BrowserLauncher.java – Browser setup
- OpenWebsite.java – Opens Demoblaze site
- SignupTest.java – User registration test
- InvalidLogin.java – Invalid login validation
- AlertHandling.java – Alert/popup handling
- AddtoCart.java – Add product to cart
